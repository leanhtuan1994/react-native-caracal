## 10.2.0

### Features

- Layouts adapt to the iPhone Duo, iPad and other resizable windows. Scroll content is padded with the left and right safe area insets, so the side status bar, camera and tab bar on the Duo cover display no longer cover it. On wide windows, the auth screens, Profile and Settings center a readable column, and the Home feed shows two columns from 768 pt. See the [iPhone Duo & Foldables](/docs/ui-and-theme/iphone-duo) guide.
- Added `useScrollTopPadding()` (`@/lib/hooks`). It keeps a top gap on tab screens when the top safe area inset is 0, as on the Duo cover display, and adds nothing below a notch or Dynamic Island. On Android it returns the status bar inset and replaces `android:pt-safe`.
- Added screenshots, GIFs and videos of the app on iPhone 18 Pro and the iPhone Duo to the README and the docs (`docs/public/screenshots/`).

### Fixes

- Release builds showed raw translation keys such as `home.all`. The root layout now imports `@/lib/i18n`, so i18next is initialized before any screen renders.
- `AmbientBackground` and the onboarding `PanelGlow` now redraw their SVG gradients when the window resizes. They kept the size of their first draw, so after unfolding the Duo the background covered only part of the screen.
- Onboarding feature cards use a minimum height instead of a fixed one, so text no longer clips on narrow windows.

### Dependencies

- Updated to the latest Expo SDK 58 patch releases: Expo `58.0.17`, Expo Router `58.0.25`, and matching `expo-constants`, `expo-linking`, `expo-splash-screen`, `expo-status-bar`, `@expo/metro-runtime` and `jest-expo`.

### Breaking changes

- Removed the `WIDTH` and `HEIGHT` exports from `@/components/ui`. They read the screen size once at startup, which is wrong after the window resizes. Use `useWindowDimensions()` or Uniwind breakpoints instead.

## 10.1.0

### Dependencies

- Upgraded to Expo SDK 58: Expo `58.0.16`, Expo Router `58.0.24`, React Native `0.88.0`, and React `19.3.0`. All Expo-managed packages now use the versions required by SDK 58, including `react-native-gesture-handler` 3, Reanimated `4.7`, Worklets `0.13`, and FlashList `2.3`.
- Upgraded Jest to 30 and React Native Testing Library to 14, which replaces `react-test-renderer` with `test-renderer`. Also updated `@react-native/jest-preset` and `@react-native/metro-config` to `0.88.0`.
- Updated Uniwind to `1.13.0`, which supports the React Native 0.87+ types. Also updated `react-native-mmkv` to `4.3.2` and `react-native-nitro-modules` to `0.37.1`. Nitro `0.36.2` or later is required for React Native 0.87+, because older versions fail with `installJSIBindingsWithRuntime: was not called`.
- Updated HeroUI Native to `1.0.11`, which accepts `react-native-gesture-handler` 3 and clears the unmet peer dependency warning. This release also applies `className` colors that `1.0.10` ignored, so selected tag chips now render with the dark `bg-foreground` fill and glass button labels use `text-foreground`, as the components specify.

### Fixes

- Installed `expo-symbols`, which Expo Router 58 requires for the Android `md` icons on `NativeTabs.Trigger.Icon`. Without it, Android crashed with a render error when opening the signed-in tabs.
- The Home, Profile, and Settings tabs now pad their content below the status bar on Android. They relied on `contentInsetAdjustmentBehavior`, which only works on iOS, so with edge-to-edge the headers were drawn under the Android status bar. The root layout now passes safe area insets to Uniwind through `SafeAreaListener`, and the tab screens use `android:pt-safe`.
- Replaced `react-native-edge-to-edge` with `expo-status-bar`. Expo SDK 58 enables edge-to-edge on Android by default with transparent system bars, so the package, its config plugin, and the Expo Doctor exclusion are no longer needed. `FocusAwareStatusBar` now renders `StatusBar` from `expo-status-bar`.
- Route guards now pass an explicit `redirectTo` from `getRouteGuards`. Expo Router 58 otherwise sends a guarded route to the first unguarded route in file order, so a fresh install opened on the not-found screen instead of onboarding.
- CI now uses Node.js 22, because Expo SDK 58 tooling requires Node.js 22.13 or newer.
- `NativeTabs` is now imported from `expo-router/native-tabs`. The `expo-router/unstable-native-tabs` entry point is deprecated.

### Breaking changes

- The `render` and `setup` helpers in `@/lib/test-utils` are now async because React Native Testing Library 14 made rendering async. Use `await setup(...)` and `await render(...)` in tests. The wrapper no longer adds a `NavigationContainer`, because Expo Router 58 no longer exports it.
- `tsconfig.json` now extends `expo/tsconfig.base.json`. Expo 58 added package `exports`, so the old path without an extension no longer resolves for the ESLint import resolver.

Caracal ships with the [Space Grotesk](https://fonts.google.com/specimen/Space+Grotesk) family from `@expo-google-fonts/space-grotesk`, loaded at runtime in `src/app/_layout.tsx`. Each weight is registered under the family name that the `--font-*` variables in `src/themes/sky.css` use:

```tsx title="src/app/_layout.tsx"
import { SpaceGrotesk_400Regular } from '@expo-google-fonts/space-grotesk/400Regular';
import { SpaceGrotesk_500Medium } from '@expo-google-fonts/space-grotesk/500Medium';
import { SpaceGrotesk_600SemiBold } from '@expo-google-fonts/space-grotesk/600SemiBold';
import { SpaceGrotesk_700Bold } from '@expo-google-fonts/space-grotesk/700Bold';
import { useFonts } from 'expo-font';

export default function RootLayout() {
  const [loaded] = useFonts({
    'SpaceGrotesk-Regular': SpaceGrotesk_400Regular,
    'SpaceGrotesk-Medium': SpaceGrotesk_500Medium,
    'SpaceGrotesk-SemiBold': SpaceGrotesk_600SemiBold,
    'SpaceGrotesk-Bold': SpaceGrotesk_700Bold,
  });

  if (!loaded) {
    return null;
  }

  // ...
}
```

The app renders nothing until `loaded` is true, which keeps text from flashing in a fallback face.

<Callout type="warn">
Import each weight by its **subpath**, and take `useFonts` from `expo-font` rather
than from the font package. The package barrel re-exports every weight and italic
the family ships — for Inter that was 18 files — and all of them are linked into the native
build, because React Native resolves fonts by name at runtime and no bundler or
shrinker can prove the unused ones dead. An ESLint rule enforces this.
</Callout>

## Adding another Google Font

Install the family and swap the imports above:

```bash
pnpm add @expo-google-fonts/roboto
```

```tsx
import { Roboto_400Regular } from '@expo-google-fonts/roboto/400Regular';
```

No prebuild is needed — these packages ship the font files as JS assets.

## Adding a local font file

For a font that is not on Google Fonts, create an `assets/fonts` folder (the starter has none, since Space Grotesk ships as a package), put the file in it, and register it with the `expo-font` config plugin. Caracal already lists the plugin in `app.config.ts`; add a `fonts` array to it:

```ts title="app.config.ts"
import type { ConfigContext, ExpoConfig } from '@expo/config';

export default ({ config }: ConfigContext): ExpoConfig => ({
  ...config,
  plugins: [
    [
      'expo-font',
      {
        fonts: ['./assets/fonts/SpaceGrotesk-Regular.ttf'],
      },
    ],
  ],
});
```

<Callout type="info">
This links the font natively, so you need to run `pnpm prebuild` and then `pnpm ios` or `pnpm android` before the font is available. A local font added this way does not need `useFonts`.
</Callout>

## Using the font in your components

Font families are theme tokens, set in `src/themes/sky.css` — not in a `tailwind.config.js`. Update the `--font-*` variables in **both** the `@variant light` and `@variant dark` blocks:

```css title="src/themes/sky.css"
@layer theme {
  :root {
    @variant light {
      --font-normal: "SpaceGrotesk-Regular";
      --font-medium: "SpaceGrotesk-Medium";
      --font-semibold: "SpaceGrotesk-SemiBold";
      --font-bold: "SpaceGrotesk-Bold";
      /* ... */
    }
  }
}
```

The value must match the name the font is registered under — the key you pass to `useFonts` (Caracal remaps the `@expo-google-fonts` exports to `SpaceGrotesk-*` names), or the file's PostScript name for a local file. These tokens back the `font-normal`, `font-medium`, `font-semibold`, and `font-bold` class names, and HeroUI Native components read them too:

```tsx
<Text className="font-bold text-lg">Hello</Text>
```

More details can be found in the [Uniwind documentation](https://docs.uniwind.dev/) and the [expo-font docs](https://docs.expo.dev/versions/latest/sdk/font/).

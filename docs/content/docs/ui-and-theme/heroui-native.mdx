Caracal uses [HeroUI Native](https://heroui.com/en/docs/native) (v1.1.1) as the primary UI component library, providing 30+ production-ready components with built-in accessibility, theming, and styling.

## Buttons and form fields

Use HeroUI components from `heroui-native`. Buttons support semantic variants such as `primary`, `secondary`, `danger` and `ghost`. Compose a label and input inside a `TextField`.

```tsx
import { Button, Input, Label, TextField } from 'heroui-native';

export function EmailField({ onContinue }: { onContinue: () => void }) {
  return (
    <>
      <TextField>
        <Label>Email</Label>
        <Input keyboardType="email-address" autoCapitalize="none" />
      </TextField>
      <Button variant="primary" onPress={onContinue}>
        <Button.Label>Continue</Button.Label>
      </Button>
    </>
  );
}
```

The sign-in and registration screens use the template’s `ControlledInput` to connect a HeroUI field to React Hook Form and translated validation messages. See [Forms](/docs/ui-and-theme/forms).

## Bottom sheets

The template includes the native TrueSheet dependency. Rebuild the development client when adopting it. Use [Modal and useModal](/docs/ui-and-theme/custom-components#modal-component) for a sheet with a title and close button. Use HeroUI’s compound `BottomSheet` directly for custom headers or sticky footers.

## Theme and component examples

`src/app/_layout.tsx` mounts `HeroUINativeProvider` inside the app theme provider. Shared color tokens live in `src/themes/sky.css`. See [UI & Theming](/docs/ui-and-theme/ui-theming) and [component examples from the app](/docs/ui-and-theme/component-showcase).

For other variants and their supported props, see the [HeroUI Native component reference](https://heroui.com/en/docs/native/components).

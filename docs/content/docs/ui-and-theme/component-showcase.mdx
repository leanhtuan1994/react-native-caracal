## Explore the app

| Where to look | What to try | Implementation |
| --- | --- | --- |
| Sign in and Create account | Submit an empty form, then toggle password visibility. | `src/components/auth/login-form.tsx`, `src/components/ui/controlled-input.tsx` |
| Home | Search for a post, filter by tag and open its detail screen. | `src/components/home/`, `src/app/posts/[id].tsx` |
| Settings | Switch theme or language. | `src/components/settings/` |

## Use a component in your own screen

The [Modal example](/docs/ui-and-theme/custom-components#modal-component) shows how to present a HeroUI bottom sheet and close it through its ref. For individual components and interactive previews, use the [HeroUI Native component reference](https://heroui.com/en/docs/native/components).
